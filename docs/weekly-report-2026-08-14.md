# 周报：场景重建准确率 + Debate 多智能体

> 2026-08-14，对应学长本周两个任务：可度量的场景重建准确率；带相机位姿与变换矩阵的 debate。

## 1. 场景重建准确率

### 用什么、怎么算

- 单位：10x10 网格，1 格约等于场景宽/深的 1/10。
- 输入：模型三视图 JSON 和 GT 三视图（由 VSI-Bench meta_info 的 3D bbox 转成同一 10x10 网格）。
- 对齐：先按 TOP 视图做刚性对齐，用实例级匹配估计旋转 R、平移 (dx, dy)，必要时允许镜像；scale=1，即不拟合尺度。
- 逐视图误差：
  - TOP：对齐后的 (x, y) 与 GT (x, y) 的欧氏距离；
  - FRONT：横向 x 复用 TOP 变换，z 保持原始，与 GT (x, z) 比；
  - SIDE：横向 y 复用 TOP 变换，z 保持原始，与 GT (y, z) 比。
- 实例匹配：每个类别内 greedy 最近邻匹配，逐样本对已匹配实例求平均误差。
- 汇总：按 arm × 视图给平均/中位误差，并拆 failure（QA 错）和 correct（QA 对）样本的差距。

### 200 样本结果（161 个能匹配上实例的样本）

| arm | 视图 | 平均误差 | 中位误差 | failure 平均 | correct 平均 | 差距 |
|---|---|---|---|---|---|---|
| baseline | top | 0.95 | 0.88 | 1.13 | 0.71 | +0.42 |
| threeview | top | 0.93 | 0.97 | 1.00 | 0.82 | +0.18 |
| threeview | front | 1.54 | 1.50 | 1.64 | 1.39 | +0.25 |
| threeview | side | 1.52 | 1.48 | 1.61 | 1.40 | +0.22 |

结论：failure 样本的逐物体位置误差普遍高于 correct 样本，差距越大说明“位置建得准不准”和“QA 对不对”越相关；TOP 误差约 1 格，FRONT/SIDE 因 z 未补偿约 1.3-1.6 格。

## 2. Debate：思路与细节

### 学长要求的核心

每个 agent 有自己的 position / look_at / look_up（等价相机），不同 agent 的坐标系不一定严格 90° 对齐，需要通过变换矩阵把对方地图对齐到自己的相机系；先做最基础的 1 轮 debate，之后可以在 Unity 场景里自由切换视角并自动对准。

### 版本演进

- v1/v2：TOP/FRONT/SIDE 三个 agent 各建一个视图并互评，但没有相机矩阵，只有共享轴偏移。
- v4（保留为尝试）：2 个 agent，每个建完整三视图，用 3D rigid transform 对齐融合。
- v5（当前主方案）：3 个 agent 各建一个视图，引入各自相机位姿和矩阵对齐。

### v5 流程

1. 相机定义：
   - TOP：position=[5,10,5]，look_at=[5,0,5]，look_up=[0,0,-1]
   - FRONT：position=[5,0,15]，look_at=[5,0,5]，look_up=[0,1,0]
   - SIDE：position=[15,0,5]，look_at=[5,0,5]，look_up=[0,1,0]
2. 建图：三个 agent 各自只看视频，输出自己的 TOP / FRONT / SIDE 视图，共 3 次调用。
3. 第一轮互评（A）：v2 式结构化修正，给每个 agent 其他视图和共享轴偏移量（top.x-front.x、top.y-side.y、front.z-side.z），输出修正视图。
4. 第二轮互评（C）：把修正后的三视图按共享轴合并成融合三视图参考（目前是 2D 平均，暂不是真 3D 重建），估计每个视图到 TOP 参考系的 rigid transform，把融合参考重投影回该 agent 自己的视图，再输出最终视图。
5. 融合：三个最终视图统一到 TOP 参考系，得到最终三视图地图。
6. 回答：TOP agent 的会话贯穿建图、两轮互评、融合地图、回答（带视频记忆），和 3-pass shared 公平对比。

### 矩阵相关细节

- view matrix：由 position/look_at/look_up 构造 4x4 矩阵。forward=normalize(target-position)，right=cross(forward, up)，up'=cross(right, forward)；旋转 R 的行取 [right, up', -forward]（OpenGL）或 [right, up', forward]（Unity），平移 t=-R·position。
- agent 间变换：A、B 各自有 view matrix M_A、M_B，B 到 A 的变换 T = M_A · M_B^{-1}，即“把 B 坐标系里的点搬到 A 坐标系”。
- rigid transform：用实例级匹配点对做 Kabsch/Umeyama，估计 y = R·x + t；det(R)<0 时允许镜像；返回 RMSE 判断对齐质量。
- v5 实际使用的是每视图到 TOP 的 2D rigid transform（FRONT 的 x/z、SIDE 的 y/z 分别对齐到融合参考），并记录 R、t、mirror、rmse，方便 Unity 复现；匹配点少于 2 时回退 analytic 相机矩阵先验。
