# Failure Case Analysis

> 基于 VSI-Bench 50 样本；错误案例 = QA 答错的样本（baseline 38/50、threeview 35/50、threeview_3pass 33/50）。所有地图均对齐到 GT 坐标系后再诊断。

## 1. 地图问题普遍存在，不是错误案例独有

| 问题 | baseline 错误/正确样本中出现率 | threeview 错误/正确 | 3-pass 错误/正确 |
|---|---|---|---|
| 漏画实例 | 21% / 25% | 23% / 20% | 21% / 29% |
| 多画实例 | 13% / 17% | 6% / 0% | 6% / 29% |
| 相对距离画错 | 84% / 100% | 91% / 87% | 82% / 94% |
| 相对方向错 | 63% / 92% | 74% / 80% | 64% / 88% |
| z 整体偏高 | - | 86% / 87% | 58% / 65% |

但是：距离错、方向错、z 偏高在正确样本里同样高频出现。

## 2.题目关键物体被漏画或严重错位

错误案例里，往往不是整体地图乱，而是**题目真正要比较的那个物体**出了问题：

- 样本 11 `scene0221_01`（rel_distance，问 microwave 最近谁）：microwave 三个视图全漏，模型只能乱答。
- 样本 12 `scene0307_02`（问 radiator 最近谁）：radiator 单物体偏移 4.7 格，door/window 各漏 4/2 个。
- 样本 14 `scene0653_00`（问 door 最近谁）：monitor 漏 6、table 漏 5，关键类别严重缺实例。
- 样本 2 `47334103`（abs_distance）：stool 多画 1 个，table 偏移 2.0 格，距离答案从 3.7 变成 0.3。

## 3. 漏画严重程度与物体数量强相关，错误案例更集中在多实例/小物体场景

- GT 实例 1-2 个：漏画率 0%
- GT 实例 3-5 个：约 1%
- GT 实例 6-10 个：32~44%
- GT 实例 >10 个：75~77%

小物体摆放也更差

## 5. 回答阶段也是错误来源

样本 2 `47334103` 在尺度+z 补偿后 stool/table 位置都对（✓），但四个 arm 的 QA 全部答错。这类案例说明：即使地图相对布局正确，答案仍可能错，地图→回答的转换环节是独立瓶颈，不能全部归因于建图。

## 6. 小结

1. 建图问题（漏画、距离/方向错、z 偏高）是**全样本普遍存在**的，不是错误案例独有的特征。
2. QA 错误 = “题目关键物体漏画/严重错位 + 多实例/小物体场景 + 回答阶段误差”。
