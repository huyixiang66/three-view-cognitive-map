## 4. 结论

1. v4 证明“相机帧 + 变换矩阵”路线可行：矩阵能估计、地图一致性改善、QA 不再倒挂。
2. 但当前还只是与 3-pass 打平，没超过；差距主要在部分 rel_distance / route 题。
3. 下一步候选：增大 agent 数量 / 轮数、把 3D 对齐结果真正用于融合（现在 answer 只用 agent A 地图）、修复答案解析 None。
