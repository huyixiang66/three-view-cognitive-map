# 项目计划 — 建图问题分析 + VSI-Bench 200 条扩样（2026-08-07 v2）

## 1. 背景与目标

主线：Unity/三视图认知图提升 VLM 在 VSI-Bench 空间 QA 上的表现。当前聚焦**建图本身（cogmap）**：模型地图对齐到 GT 坐标系后，用**离散/拓扑级指标**诊断建图错误；并扩大样本（VSI-Bench 200 条）增强稳健性。

## 2. 已完成

- 四组实验：TIS baseline / Three-view 单次 / 3-pass / 两阶段计数（各 50）
- 对齐方案：TOP 旋转+平移（必要时镜像），z 直接比
- 分析文档：cogmap-dictionary / analysis / direction-bias / aligned-absolute-metrics / failure-case-analysis / threeview-vs-tis-results
- 桶1 人工核对 7/7

## 3. 关键发现（50 样本）

1. 绝对精度差：对齐后 cell 命中仅 11~13%，逐物体 MAE 1.7~1.9 格
2. rel_distance 类系统性偏右（+0.8~0.9 格）；三视图 z 整体偏高（+1.19 格）
3. 镜像 19~26/50；单次 vs 3-pass 地图差异小，3-pass 无地图增益
4. 漏实例：chair 漏 45~51/arm；VLM 计数不可靠（两阶段实验）
5. 平移量中位约 4 格（原点差异主导）

## 4. 分析指标（v2：只保留直指建图的离散/拓扑指标）

> 连续残差（MAE / cell 命中 / 方向偏置 dx、dy）**全部弃用**：它们与坐标转换/对齐估计纠缠，不能单独归罪建图。

### 4.1 不变指标（保留）

| 指标 | 定义 | 直指问题 |
|---|---|---|
| A1 漏实例率 | 每类模型实例数 < GT | 漏画/计数不足 |
| A2 多实例率 | 模型实例数 > GT | 拆分/多画 |
| 对偶距离准确率（8 bin） | 类别对距离差 ≤1 格 | 相对布局，局部 vs 全局 |
| 紧邻对准确率 | GT 距离 ≤1 格的类别对 | 近邻布局 |
| 尺度中位数 | 模型距离/GT 距离比值 | 整体压缩/放大 |
| C6/C7/C8 | 跨视图冲突/缺失/高度排序 | 三视图自洽与高度 |

### 4.2 对齐后新解锁（主指标，离散/拓扑/身份）

| 指标 | 定义 | 稳健性 | 直指问题 |
|---|---|---|---|
| 相对顺序准确率 | 对齐后逐对比较左右（x）与前后（y）顺序，与 GT 一致率；排除轴差 <0.5 格的近似平局对 | 平移/尺度不变，旋转由对齐处理 | 局部/整体顺序画反、镜像 |
| 相对方向分类准确率 | 逐对物体按 8 方向（E/NE/N/NW/W/SW/S/SE）分类，模型 vs GT 精确一致率与 ±1 方向容差率 | 离散分类，对小幅残差稳健 | 方向关系系统性错误（如 E↔W 混淆） |
| 邻接图边匹配率 | GT 与模型分别建 k-NN（k=1,3）图，边集 Jaccard/F1；含“最近邻命中率”（k=1） | 邻接对小幅位移稳健 | 局部拓扑“谁和谁挨着”是否搭对 |
| 实例错位率 | 类别内按最近邻做实例匹配，统计匹配到“错误 GT 实例”的比例（串位） | 需对齐后身份可判 | 张冠李戴、复制粘贴、实例级错位 |
| 镜像证据分 | 非镜像与镜像两种对齐下比较“x 顺序违反数”；违反数大幅下降则判定镜像建图错误 | 顺序证据，非方法假设 | 左右翻转是否真实存在 |
| z 绝对高度误差与偏置 | 逐物体 z 差（无坐标转换），均值/偏置方向一致率 | z 轴天然可比 | 高度系统性偏高/偏低 |

### 4.3 内部伪影（无需 GT，辅助）

| 指标 | 定义 | 直指问题 |
|---|---|---|
| 实例堆叠率 | 同类多实例中心距 <0.5 格比例 | 复制粘贴/重复 |
| 网格偏好 | 坐标集中在整数/0/9 边缘的比例 | 强先验式猜测 |
| 分布熵 | 物体位置熵 vs 均匀网格熵 | 挤团/只覆盖局部 |

## 5. 扩样决策（已收敛）

- 来源：**VSI-Bench**（ReVSI 暂缓；结构不同需适配器）
- 规模：200 条，VSI 8 类各 25，类内按数据集分层随机，固定随机种子
- 分析口径：200 条整体 + 分题型（不做双轨）
- 样本格式：沿用 vsi_subset_50 字段（dataset/scene_name/question_type/question/options/ground_truth）

## 6. 下一步实现清单

1. 获取完整 VSI-Bench QA（hf-mirror），解析 8 类题型与字段
2. 写 `src/sample_vsi_200.py`：8 类×25、分层随机、固定 seed，导出 `src/vsi_subset_200.json`
3. 核对本地视频缓存覆盖，列出缺失视频（运行前需下载）
4. 复跑 4 个 arm（200 条），每 5 样本自动保存
5. 写新指标计算脚本：相对顺序准确率、方向分类准确率、邻接图边匹配率、实例错位率、镜像证据分、z 偏置、内部伪影
6. 输出 200 条分析文档（整体 + 分题型 + 分 arm）

## 7. 风险与待办

## 8. 问题级输出与扩展字段（v3 补充）

### 8.1 问题级输出（case-level）

对齐后离散指标不直接报告数字，而是转成可检查的问题句（`src/cogmap_issues.py` → `docs/cogmap-issues.md`）：
- 漏画 chair ×2（GT 3，模型 1）/ 多画 stool ×1
- door-window 距离画错（GT 4.0，模型 6.2）
- chair→table 方向错（GT E，模型 NE）
- z 整体偏高（平均 +1.2 格）
- 实例堆叠：chair×2 画在同一格
汇总层给出每类问题出现样本数（top10/arm），逐样本列出问题清单，便于 case-by-case 检查。

### 8.2 扩展字段（新题型）

`vsi_subset_200.json` 每条新增 `ext` 字段：
- `ext.target_categories`：该题涉及的类别（counting/size/route/appearance 由问题与选项抽取）
- `ext.needs_size`：size 类题需要物体尺寸（当前 cogmap 无 size，先标记）
- `ext.room`：room_size 题，无具体物体
后续管线按 `ext` 适配：counting 用 target_categories 建 GT；size/room_size 仅 QA 分析；route/appearance 用选项抽取类别。
