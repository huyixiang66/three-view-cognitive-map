## 4. 结论

1. 对齐后三视图/3-pass 的逐物体 MAE 优于 baseline，但绝对精度仍差：cell 命中率只有 11~13%。
2. 平移量中位约 4 格、镜像 19~26 题：模型地图相对 GT 主要是原点平移和左右翻转，不是旋转。
3. 单次与 3-pass 地图差异不大（MAE≈0.9 格），3-pass 没有地图增益。
4. 对偶距离错误题数 42~45/50：逐物体绝对位置偏差大，但相对距离错误同样普遍。
