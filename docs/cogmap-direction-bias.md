# 对齐后方向/位置偏置分析

> 2026-08-07 · 每个样本用旋转+平移对齐到 GT 后，逐物体误差向量 = 模型(对齐) − GT；看是否存在系统性偏左/偏右/偏上/偏下。

## 3. z 偏置（三视图，正=偏高）

- threeview：平均 z 误差 +1.19 格，偏高 71% / 偏低 4%

## 4. 解读

- 若平均 dx/dy 显著不为 0 且偏右/偏左比例失衡，说明该 arm 有系统性位置偏置；若接近 0 且比例五五开，说明误差是随机/局部性的。
